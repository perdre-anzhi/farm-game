# 小龙庄园 v0.1（MVP）

订单驱动的休闲农场游戏单机版。对应设计文档：`../docs/游戏设计方案.md` 第 8 节 MVP 范围。

## 运行

**方式一（最简单）**：直接双击 `index.html` 在浏览器打开。
零依赖、无构建步骤，三个文件（index.html / style.css / game.js）全部本地加载，`file://` 协议可用。

**方式二（本地服务）**：

```bash
cd farm-game
python3 -m http.server 8931
# 浏览器打开 http://localhost:8931
```

存档自动保存在浏览器 localStorage（键 `morning-breeze-farm-v01`），换浏览器/清缓存会丢档；顶栏 ♻️ 可重置。

## 玩法闭环

> 种牧草(30秒) → 饲料机 牧草×3→饲料(20秒) → 喂鸡 → 收蛋(90秒) → 交订单 → 金币+经验 → Lv2 解锁小麦、Lv3 解锁 2 块新耕地（封顶 Lv5）

- 8 块初始耕地 + 鸡舍(4鸡) + 饲料机(1队列位) + 订单板(3槽，拒单/交付后 30 秒补充)
- 所有生产基于真实时间戳，关闭页面照常生长；离线收益上限 8 小时（设计原则）
- 仓库点物品可直接卖出，但订单价约 1.8 倍且带经验——鼓励走订单

## 调成正式版时长

`game.js` 顶部配置区的"正式版"数值写在注释里，直接替换即可：

| 配置 | DEMO 值 | 正式版值 |
|---|---|---|
| 牧草 growMs | 30 秒 | 5 分钟 |
| 小麦 growMs | 2 分钟 | 30 分钟 |
| 饲料加工 ms | 20 秒 | 30 分钟 |
| EGG_MS | 90 秒 | 6 小时 |

## 结构

```
farm-game/
├── index.html   # 页面骨架（顶栏/地图/仓库栏/弹层）
├── style.css    # 全部样式（草原配色、格子地图、面板、动效）
└── game.js      # 游戏逻辑（配置区/存档/时间系统/订单/渲染循环/事件委托）
```

渲染策略：玩家操作才全量重绘 DOM；每秒 tick 只原位更新倒计时与徽标（避免重建节点吞掉快速连点）。
